既存チームに説明文を設定・取得できるようにしてください。

要件:
- 既存の Team に description を追加します。文字列で0〜2000文字、空文字を許可し、空白と改行は入力どおり保持します。上限超過はエラーです。
- 既存チームIDを指定して説明文を置き換えます。未知のIDでチームを新規作成せず、既存のエラー契約に従います。不正入力や保存失敗で更新を確定させません。
- 既存の FastAPI teams router に PUT /teams/{team_id}/description を追加します。JSON の description は必須です。成功結果は既存の更新操作の流儀に合わせます。既存 GET /teams/{team_id} の結果には description を追加します。
- チーム作成の入力・挙動、および既存 PUT /teams/{team_id} のチーム名変更の入力・挙動を維持します。新規チームと移行前から存在するチームの説明文は空文字です。説明文を設定した後に名前を変更しても説明文は保持されます。
- DBに永続化し、別の Unit of Work から再読込しても同じ説明文を取得できるようにしてください。必要なマイグレーションとテストを追加してください。
- 認証・権限、Discord/LINE側の入口追加、検索、画像、外部サービスは今回の範囲外です。

リポジトリの AGENTS.md と関連ドキュメントを読み、既存のアーキテクチャと実装パターンに従って、最小限の変更で実装してください。`.agents/skills` があれば関連する SKILL.md を確認してください。実装後に適用可能な品質チェックを実行し、変更内容、実行したチェック、その結果、残る制限を報告してください。
