# ユースケース

「何ができるか」は[目的](purpose.md)に定義する。ここでは契機・行動・結果を定義し、
技術的な選択は[実現方法](architecture.md)に分ける。

## 共通する言葉

- 支援方針: マスターが共有する支援対象、望む結果、任せる範囲。
- 支援活動: 一つの目的に向けた継続中の仕事。会話が終わっても残る。
- 仲間: 固有の価値観・関心・判断を持ち、支援活動を担当するキャラクター。
- 根拠: 実際の発言、観測、資料、実行結果。解釈や要約とは区別する。
- 記憶: 根拠から整理した、訂正可能な理解・経験。

## U1 継続する支援方針を共有する

**契機:** マスターが新しい支援対象を示す。

1. 対象、望む結果、任せる範囲を共有する。
2. 担当と、達成を確認する条件を決める。
3. 支援活動を開始できる状態にする。

**結果:** 支援目的と担当が残り、新しい発言を待たずに着手できる。
対象が不明なら具体化を求める。推測から無制限な支援権限を作らない。

## U2 支援機会を見つけ、次の一手を選ぶ

**契機:** 支援開始、再確認の時期、新しい情報、仲間からの引継ぎ。

1. 担当者が支援方針、未完了事項、現在の観測、必要な記憶を確認する。
2. 自分の関心と判断から、目的に寄与する具体的な一手を選ぶ。
3. 選んだ理由と、確かめる結果を残す。

**結果:** 実行する内容、または待つ理由と再確認条件が決まる。
新しい人間の投稿がなくても起こる。必要な行動がなければ待つ。

## U3 支援を実行し、結果を確かめる

**契機:** 次の一手が決まる。

1. 担当者の作業場所で対象と前回の変更を確認し、必要な調査、準備、編集、検証などを行う。
2. 実行結果と根拠、成果物を残す。
3. 達成条件と照合し、達成・継続・待機・返答待ち・引継ぎのいずれかを判断する。

**結果:** 何を実行し、何が分かり、何が残ったかを追える。
返答を待つ質問や処理の終了だけでは達成としない。失敗した場合も未確認事項を残す。

## U4 続きを管理し、必要なときに再開する

**契機:** 未完了の作業が残る、外部の変化や返答を待つ、途中で実行が止まる。

1. 未完了事項と次の確認条件、前回の判断、伝えた内容、未回答の質問を残す。
2. 条件が成立したら、目的と前回の結果を確認して再開する。
3. 前提が変わっていれば方針を見直す。

**結果:** マスターが再度説明せずに続けられる。
中断した操作の結果が不明なら、実際の状態を確認してから続ける。

## U5 仲間に引き継ぎ、異なる観点を得る

**契機:** 別の仲間の観点や作業が目的達成に必要になる。

1. 目的、対象と変更の所在、根拠、未完了事項を渡す。
2. 受け取った仲間が自分の作業場所と価値観で確認・実行する。
3. 自分の結論と理由を残して支援を続ける。

**結果:** 担当の変更と各人の判断が追える。
複数人の合意や台詞を一人が創作しただけでは、このユースケースを満たさない。

## U6 経験を記憶し、必要な根拠を読み直す

**契機:** 判断に過去の情報が必要になる、結果や訂正から新しい理解を得る。

1. 必要な記憶を探し、十分でなければ根拠へ戻る。
2. 確認できた事実と自分の解釈を分けて判断に使う。
3. 今後役立つ理解・経験を、根拠を添えて本人の記憶へ反映する。

**結果:** 同じ本人の会話と作業で記憶が判断に使われ、誤りを訂正できる。
他の仲間の記憶と同じ名前でも上書きしない。
報告の言い換えを、新しい事実や約束として記憶しない。
支援方針と、仲間が推測した好みを混同しない。

## U7 状況を伝え、訂正・追加情報・停止を受け入れる

**契機:** 伝える価値のある進展、確認事項、マスターからの変更・停止指示。

1. 作業記録を保存し、伝える必要がある内容・理由・根拠・未確認事項・質問を選んで発言する。
2. マスターは状況を確認し、情報を補い、方向を変え、活動を止められる。
3. 受け取った原文を残し、次の判断に反映する。

**結果:** 状況が分かり、意思の変更が実行へ届く。
発言した本人を識別でき、操作への応答も同じ窓口で受け取れる。
発言しない判断も記録に残る。返答待ちの質問と完了は伝える。
報告できなくても成果を失わず、停止後は新しい作業を始めない。
停止以前に外部へ反映された操作まで取り消せたとは主張しない。

## U8 会話し、必要な支援へつなげる

**契機:** マスターが挨拶、相談、質問、依頼などを話しかける。

1. 原文を残し、本人の価値観と記憶、直近の対話と活動状況から意味を理解する。
2. 会話として自分の考えを返し、必要な事実が分からなければ確認や調査につなげる。
3. 作業への依頼・訂正・停止・再開が含まれる場合だけ、該当する活動へ届ける。
4. 受付の結果を確かめて伝える。既に後続の指示があれば、それを優先する。

**結果:** 作業中も会話でき、挨拶や相槌だけで作業を中断・再実行しない。
会話の失敗時も原文が残り、支援活動は継続できる。
