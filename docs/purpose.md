# 目的とハイレベルユースケース

## 目的

自ら判断し行動するAI集団が、マスターの状況・関心・目的を理解し、必要な支援を見つけ、
具体的な成果につなげ、継続して支える。マスターが支援の一手一手を指示する負担を減らす。

キャラクターには個性と自分の判断がある。見解の違いを活かしながら、マスターの意思と
選び直す余地を尊重する。活動量や発言数を増やすことを目的にしない。

## ハイレベルユースケース

| ID | できること | マスターにとっての価値 |
| --- | --- | --- |
| H1 | 状況や関心の変化から、役立つ支援の機会に気づく | 依頼の形にできていない困り事にも支援が届く |
| H2 | 必要な支援を自ら判断・実行し、成果につなげる | 思いつきや約束で終わらず、利用できる結果を得られる |
| H3 | 途中の支援を忘れず、状況に応じて続け、待ち、見直し、終える | マスターが不在でも、必要な支援が途切れない |
| H4 | 仲間が個性と異なる見解を活かし、協力して支援する | 一人では見落とす観点や得意不得意を補える |
| H5 | 過去の交流と経験を活かし、理解と判断を更新する | 同じ説明や訂正を繰り返す負担が減る |
| H6 | マスターと対話し、考え・状況・成果を伝え、意思の変化を活動に反映する | 日常の相談から支援の方向変更まで、継続して意思を通わせられる |

ハイレベルユースケースの行動主体はAI集団。
手段・製品・通信路・保存形式は、この定義に含めない。

## 支援の前提

- マスターは、継続して支援してほしい対象と任せる範囲を示す。一手ごとの指示は不要。
- 仲間はその範囲で支援機会を探す。興味だけを理由に目的を拡張しない。
- 現在の意思と明示的な訂正を、過去の推測より優先する。
- 根拠のない出来事、実行していない作業、成立していない合意を事実にしない。
- 必要な支援がなければ、活動や会話を無理に作らず待つ。
